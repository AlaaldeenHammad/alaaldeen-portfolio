# Alaaldeen Hammad — Portfolio

A personal portfolio site for Alaaldeen Hammad, Full Stack Web Developer (Amman, Jordan).

- **Stack:** plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies.
- **Design direction:** *Modern Tech Gradient* — deep navy base, soft gradient accents, glassy cards, bento-grid projects, smooth scroll reveals.
- **Fonts:** Sora / Inter / JetBrains Mono (Google Fonts).
- **Features:** light/dark theme toggle (respects OS preference), scroll-spy nav, mobile menu, reduced-motion support, semantic landmarks and skip link.

## Structure

```
index.html
assets/
  css/style.css
  js/main.js
  img/
```

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Editing content

All content lives in `index.html`. The **Projects** section currently holds placeholder
cards derived from the CV (Hakeem Healthcare System, ministry work, agency work) — replace
the copy and add links / case-study pages as they become available.

## Deploy

Static host of choice — GitHub Pages, Netlify, Cloudflare Pages, or any web server.
